# Ответы на вопросы

## Когда ответственность за закрытие переходит к менеджеру?

В момент выполнения блока `finally`

## Почему код около yield получает исключение из тела блока?

По стеку вызовов, исключение opener передается в блок try.

## Почему нельзя закончить выход, только запустив aclose?

По аналогии с gracefull shutdown, в aclose могут быть awaitable объекты, которых желательно дождаться.
