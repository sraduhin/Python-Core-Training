**Уровень:** лёгкая · **Оценка:** 2 SP.

### Перед началом

Разберись с `async def`, `await`, объектом корутины, `Task`, `asyncio.gather` и `asyncio.Event`. Задача нужна, чтобы отличать порядок завершения операций от порядка результатов и явно выбирать поведение при ошибке.

### Условие и API

Реализуй:

```python
async def run_batch(
    items: Sequence[int],
    work: Callable[[int], Awaitable[int]],
) -> list[int | Exception]: ...
```

Вход — небольшой конечный список, не больше двадцати элементов. Запусти независимые `work(item)` конкурентно. Например, операции для `[10, 20, 10]` могут закончиться в обратном порядке, но позиции ответа должны соответствовать именно этому списку. Повторяющиеся значения обозначают отдельные вызовы.

### Контракт

- Для каждой позиции вызови `work` ровно один раз. Пустой вход возвращает `[]` без вызова `work`.
- Каждая позиция содержит число либо исходный объект обычного исключения `Exception`. Ошибка одной операции не отменяет остальные; партия ждёт все результаты.
- `work` — корректная async-функция: она возвращает число или поднимает обычное исключение, уступает управление и не отменяет сама себя. Дополнительная валидация элементов и callback не нужна.
- При одной внешней отмене партии запроси отмену незавершённых операций, дождись их `finally` и распространи `CancelledError`. Отмена не становится элементом ответа. Очистка callback завершается и не поднимает новой ошибки; повторная отмена во время очистки вне задания.
- После выхода фоновых задач партии нет. Повторные и вложенные вызовы `run_batch` независимы; лимит, тайм-аут и сеть здесь не нужны.

### Что проверить

1. Пустой вход и один элемент.
2. Три операции сообщают о старте через `Event` до разрешения закончить хоть одну: последовательный цикл такую проверку не проходит.
3. Завершение в порядке 3–2–1 сохраняет исходный порядок ответа.
4. Дубликаты запускают отдельные операции и занимают отдельные позиции.
5. Заранее созданный `ValueError` попадает в ответ тем же объектом; соседние операции успешно заканчиваются.
6. После внешней отмены все начавшиеся операции выполнили очистку до выхода партии.
7. Два независимых запуска не смешивают результаты.

Порядок задавай событиями, без `sleep` и измерения скорости. Тайм-аут теста допустим как защита от зависания. Async-сценарии можно запускать через `asyncio.run` из обычных тестов pytest.
