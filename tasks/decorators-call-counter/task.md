**Уровень:** лёгкая · **Оценка:** 2 SP.

**Предварительные знания:** функции как объекты, замыкания, `*args` и `**kwargs`, распространение исключений.

В небольшой библиотеке нужно узнать, сколько раз вызывают конкретную функцию. Реализуй декоратор, который добавляет счётчик попыток вызова и сохраняет обычное поведение функции. Эта практика помогает увидеть разницу между моментом декорирования и выполнением обёртки, а также проверить прозрачность декоратора для вызывающего кода.

### Контракт

```python
def count_calls(func): ...

# У результата декорирования должен быть метод без аргументов:
# wrapped.call_count() -> int
```

`count_calls` принимает обычную синхронную Python-функцию без `yield`. Неподдерживаемый объект, coroutine-функция, генераторная или асинхронная генераторная функция вызывает `TypeError` при декорировании. Синхронные функции, возвращающие awaitable, в этой задаче не используются.

После декорирования `call_count()` возвращает `0`. Обёртка увеличивает счётчик на единицу непосредственно перед передачей аргументов исходной функции. Поэтому учитываются успешные вызовы, исключения тела и вызовы с неверными аргументами. Вызов самого `call_count()` ничего не увеличивает.

Обёртка передаёт позиционные и именованные аргументы без изменений. Она возвращает тот же объект результата, включая `None`, и пропускает наружу тот же объект любого исключения. Повторных вызовов, преобразования результата и вывода в консоль быть не должно.

Используй `functools.wraps`: сохраняются имя, строка документации, аннотации и ссылка `__wrapped__`. Счётчик принадлежит конкретному результату декорирования. Две функции и две независимо созданные обёртки над одной функцией имеют отдельные счётчики. Поддержка одновременных вызовов из нескольких потоков не требуется.

Например, если функция один раз вернула результат, а следующий вызов поднял `ValueError`, её счётчик равен `2`. Прямой вызов через `__wrapped__` не проходит через обёртку и счётчик не меняет.

### Критерии готовности

1. Декорирование не вызывает исходную функцию; начальный счётчик равен нулю.
2. Позиционные, именованные и аргументы по умолчанию работают без изменений.
3. Результаты `None`, `False` и изменяемый объект возвращаются без замены или копирования.
4. Ошибка тела и ошибка связывания аргументов учитываются ровно один раз; исключения не подавляются.
5. `call_count()` и прямой вызов `__wrapped__` не меняют счётчик обёртки.
6. Метаданные сохранены; `inspect.signature` показывает сигнатуру исходной функции.
7. Независимые обёртки не делят состояние; неподдерживаемые функции отклоняются.
