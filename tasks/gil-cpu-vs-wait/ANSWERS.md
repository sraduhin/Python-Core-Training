# Ответы на вопросы

## Почему отношение длительностей может меняться между двумя запусками?

В длительность проверки закрадывается шум интерпретатора и операционной системы. Заспавнить пулл от запуска к запуску будет стоить по разному, но в среднем одинаково. Именно поэтому техника бенчмарков подразумевает множественные запуски.

## Почему вывод о цикле на Python нельзя автоматически перенести на любую функцию C-расширения?

В рамках задания код блокирующий. Когда, говорят "эта функция на C" - имеют ввиду, некоторую магическую сишную оптимизацию, которая освобождает gil. Так, например, работает numpy.

## Что нужно уточнить, прежде чем повторять эксперимент на free-threaded CPython?

Нужно убедиться, что это free-threaded сборка:
"The sysconfig.get_config_var("Py_GIL_DISABLED") configuration variable can be used to determine whether the build supports free threading. If the variable is set to 1, then the build supports free threading."
