# Ответы на вопросы

## Почему проверка через `mapping.get(key)` не различает отсутствие и None?

`dict.get(key)` возвращает `None` когда ключа нет или его значение — `None`.
Для варианта, когда ключ не задан можно использовать Elipsis - спец класс, удобный именно для таких подмен.

## Что произойдёт с изменяемым прежним значением, если его содержимое поменяли через другую ссылку?

Мок сохраняет ссылку на прежний объект.
Если его замутили - при выходе из менеджера вернется измененный объект.
Добавил тест 06 под этот кейс.

## Почему восстановление настройки не требует подавлять ошибку тела?

Вопрос не понятен.
Контекстный менеджер выполняет свою задачу, мокать данные.
Остальное поведение может лежать на руках разраба.
Такой ответ возможен?
